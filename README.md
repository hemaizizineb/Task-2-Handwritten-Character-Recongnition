# Handwritten Character Recognition 📝

A Python-based project for recognizing handwritten characters using machine learning techniques. This project is part of the Code Alpha internship program.

## 🌟 Features

- Recognizes handwritten characters with high accuracy
- User-friendly interface for input
- Real-time character recognition
- Support for multiple character styles
- Detailed visualization of recognition results

## 🛠️ Technologies Used

- Python 3.x
- TensorFlow/Keras
- OpenCV
- NumPy
- Matplotlib
- scikit-learn

## 📊 Model Architecture

The project uses a Convolutional Neural Network (CNN) architecture for character recognition:

- Input Layer: 28x28 grayscale images
- Multiple Convolutional layers with ReLU activation
- MaxPooling layers for feature extraction
- Dense layers for classification
- Output layer with softmax activation

## 📈 Performance

- Training Accuracy: ~98%
- Validation Accuracy: ~96%
- Test Accuracy: ~95%
